Política de Privacidade — Hermes Workspace

Ferramenta de automação pessoal · Última atualização: 22 de outubro de 2026

O que é este aplicativo

O "Hermes Workspace" é uma ferramenta de automação de uso pessoal, operada por uma única pessoa, para gerenciar os próprios dados no Google (Gmail, Agenda, Drive, Planilhas e Documentos). Não é um produto oferecido ao público.

Quais dados são acessados

O aplicativo acessa, via API do Google, apenas os dados da própria conta Google do operador, exclusivamente para executar ações solicitadas pelo próprio operador (leitura, criação e edição de arquivos, e-mails e eventos).

Como os dados são usados

Os dados são usados somente para a finalidade declarada acima. Nenhum dado é vendido, compartilhado ou transferido a terceiros. Não há coleta de dados de outros usuários.

Armazenamento e segurança

As credenciais de autorização (OAuth 2.0) são armazenadas localmente, no equipamento do operador. Os dados processados permanecem nas contas e serviços do próprio Google.

Revogação de acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Contato

Dúvidas: utilize o e-mail de suporte informado na tela de consentimento do aplicativo.
